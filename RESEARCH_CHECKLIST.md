# M.Tech research checklist

- [ ] Fix the target language (e.g. ISL) and obtain expert validation of labels.
- [ ] Define annotation protocol, signer IDs, session IDs and gesture boundaries.
- [ ] Collect diverse signers and recording conditions.
- [ ] Keep signer-independent train/validation/test partitions.
- [ ] Compare Random Forest and LSTM under identical partitions.
- [ ] Add face and pose landmarks for non-manual features.
- [ ] Add temporal segmentation and repeated-sign handling.
- [ ] Add language model trained on a suitable licensed corpus.
- [ ] Evaluate macro-F1, per-class recall, confusion matrix, latency and FPS.
- [ ] Evaluate continuous transcription using Word Error Rate.
- [ ] Report limitations and confidence intervals; do not claim an unverified 95%.
